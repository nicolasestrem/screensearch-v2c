| 94 | 2026-07-04 | **Flow overlay hotkey one-shot remap can't distinguish a deliberate `Ctrl+Alt+Space` from a stale default.** The default changed to `Ctrl+Alt+Z` (old one collided with Claude Desktop); `load_overlay_hotkey` remaps a stored exact `Ctrl+Alt+Space` to the new default. **The remap was originally value-only, so it re-fired on every load** — a user who set `Ctrl+Alt+Space` back had it silently clobbered again next load (PR #80 codex P2), i.e. the "reversible" claim didn't actually hold. | **Fixed (PR #80 review follow-up):** the remap is now gated by a persisted marker (`overlay.hotkey_migrated`), latched on the first load under the new default regardless of the stored value, so it fires **at most once per install**. After that the stored chord is honored verbatim — a deliberately re-chosen `Ctrl+Alt+Space` is durable across restarts (test `overlay_hotkey_deliberate_legacy_survives_after_migration`). The first-load ambiguity (a leftover old default vs. a deliberate old default at upgrade time) is still resolved in favor of remapping — accepted, since the collision makes the old value a poor pre-upgrade choice and it's now one-shot + genuinely reversible. Separately, TODO-3 (a Settings-level cross-chord *conflict check* between overlay & marks hotkeys) remains open by prior decision — this change doesn't implement it. | user+agent | closed (fixed) / TODO-3 → live row #100 |
